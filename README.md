# Healthcare Patient Data Analysis using MySQL

## 📌 Project Overview

Analyzed healthcare patient data using MySQL to generate insights on patient demographics, diseases, treatment costs, hospital stays, and health indicators.

## 🛠️ Technologies Used

* MySQL
* MySQL Workbench
* SQL

## 📊 SQL Concepts Used

* SELECT, WHERE, GROUP BY, HAVING
* Aggregate Functions
* CASE Statements
* Subqueries
* Window Functions
* Date Functions

## 📁 Project Files

* `healthcare_patient_data_analysis.sql` – Database, patient records, and SQL analysis queries.

## 🎯 Outcome

Generated healthcare-related insights using SQL queries and practiced real-world data analysis concepts.
